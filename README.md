# الكيورا شيفر | بوت واتساب عربي

بوت Node.js يرد على الأوامر التي يرسلها المستخدم في محادثة واتساب. يستخدم `whatsapp-web.js` للاتصال عبر WhatsApp Web، و`qrcode-terminal` لعرض رمز الربط في الطرفية.

> **بلا هبد:** القائمة هنا تفاعلية بالنص والأرقام، وليست أزرار واتساب أصلية قابلة للنقر. مكتبات WhatsApp Web غير الرسمية وواجهاتها تتغير، ولا أعد بدعم أزرار أصلية أو استمرار الاتصال دون انقطاع. هذا المشروع لا يستخدم API خارجيًا.

## المتطلبات

- Node.js 20 أو أحدث.
- واتساب على الهاتف لربط الجلسة.
- تثبيت المكتبات من npm عندك.

## التشغيل

```bash
npm install
npm run check
npm start
```

امسح رمز QR الظاهر في الطرفية من تطبيق واتساب: **الأجهزة المرتبطة ← ربط جهاز**. بعد نجاح الربط، احفظ مجلد `.wwebjs_auth` بأمان؛ يحتوي على بيانات جلسة الدخول ولا تشاركه أو ترفعه إلى Git.

## الأوامر

أرسل أحد الأوامر التالية في المحادثة:

- `!مساعدة` أو `!help` — عرض الأوامر.
- `!قائمة` أو `!menu` — فتح القائمة النصية.
- `!ping` — فحص استجابة البوت.
- `!وقت` أو `!time` — الوقت المحلي للجهاز الذي يشغّل البوت.
- `!عن` أو `!about` — معلومات عن البوت.

بعد فتح القائمة، أرسل رقم الخيار خلال دقيقتين. البوت لا يرسل رسائل جماعية ولا يبدأ محادثات؛ يرد فقط على الرسائل الواردة والأوامر.

## ملاحظات

- المشروع يستخدم عميل WhatsApp Web غير رسمي؛ استخدامه قد يخالف شروط واتساب أو يتوقف عند تغييرات الخدمة. استخدمه على مسؤوليتك، وبموافقة أصحاب المحادثات.
- شغّل نسخة واحدة من البوت على مجلد جلسة واحد.
- لإعادة ربط الحساب، أوقف البوت واحذف `.wwebjs_auth` يدويًا ثم شغّله من جديد.
- لا ترفع `.wwebjs_auth` أو رمز QR أو أي بيانات جلسة إلى المستودع.
