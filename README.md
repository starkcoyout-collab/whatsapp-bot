# ✦ الكيورا شيفر — بوت واتساب عربي ✦

مشروع Node.js منظّم يستخدم Baileys للاتصال بواتساب ويب، مع اقتران برمز الهاتف بدل عرض QR، وبادئة أوامر افتراضية `.`.

## التثبيت والتشغيل

يتطلب Node.js 20 أو أحدث. انسخ `.env.example` إلى `.env` واكتب رقمك الدولي في `PAIRING_NUMBER` (أرقام فقط، مثل `15551234567`). ثبّت الحزم بنفسك ثم شغّل:

```bash
npm install
npm run check
npm start
```

في واتساب: **الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف**، ثم أدخل رمز الاقتران الذي يظهر في الطرفية. لا يظهر QR. بعد الربط تحفظ بيانات الجلسة في `baileys_auth_info` محليًا؛ لا تشاركها ولا ترفعها إلى Git. لا تشغّل نسختين على مجلد الجلسة نفسه.

## الأوامر

- `.قائمة` — قائمة مختصرة قابلة للاختيار بالأرقام العربية أو الإنجليزية.
- `.مساعدة` — دليل الأوامر.
- `.ping` أو `.فحص` — التحقق من الاتصال.
- `.وقت` — الوقت المحلي للجهاز.
- `.عن` — مدة التشغيل والذاكرة والنظام.
- `.حاسبة (12+8)*3` — آلة حاسبة للعمليات الأساسية بدون `eval`.
- `.تصويت السؤال؟ | خيار ١ | خيار ٢` — إنشاء استطلاع واتساب (من خيارين إلى 12).
- `.معلومات` — معلومات المجموعة.
- `.رابط` — رابط الدعوة، للمشرف فقط، والبوت يجب أن يكون مشرفًا.
- `.منشن` — رد على رسالة عضو واكتب الأمر؛ متاح لمشرف المجموعة.
- `.قفل` / `.فتح` — تحويل المجموعة إلى وضع إرسال المشرفين / الوضع العادي؛ يتطلب صلاحيات المشرف للبوت ولصاحب الأمر.
- `.ترحيب تشغيل` / `.ترحيب إيقاف` — تفعيل أو إيقاف ترحيب الأعضاء الجدد؛ للمشرفين.

الأوامر التي تتطلب تعديل إعدادات المجموعة تتحقق من صلاحية المرسل ومن كون البوت مشرفًا عند الحاجة. توجد مهلة بسيطة بين أوامر كل مستخدم. لا توجد رسائل جماعية أو أوامر إرسال تلقائي لمحادثات غير طالبة.

## القائمة والأزرار — توضيح مهم

القائمة المزخرفة تستخدم ردودًا رقمية نصية، وليست أزرار واتساب أصلية قابلة للنقر. دعم الرسائل التفاعلية يتغير بين إصدارات واتساب وBaileys، لذلك لا أدّعي أن هذه أزرار أصلية. أمر التصويت ينشئ استطلاع واتساب حقيقيًا عبر Baileys.

## هيكل المشروع

- `src/index.js` — اتصال Baileys، الاقتران، إعادة الاتصال والأحداث.
- `src/handlers/message.js` — استقبال الرسائل وتوجيهها.
- `src/commands/` — أوامر عامة وأوامر المجموعة منفصلة.
- `src/lib/` — القائمة، الصلاحيات، التخزين، الحاسبة، النصوص ومحدد المعدل.
- `src/config.js` — إعدادات البيئة والبادئة.

## ملاحظات

Baileys مكتبة غير رسمية تتصل بخدمة واتساب؛ قد تتغير أو تتعطل، وقد يخضع استخدامها لشروط واتساب. لا يوجد ضمان لاستمرار الجلسة. استخدم حسابك وبموافقة أعضاء المجموعة، واحفظ ملفات الاعتماد بسرية. الإصدار المثبت في `package.json` هو `7.0.0-rc.14` (مرشح إصدار)، وليس إصدارًا نهائيًا؛ تحقق من إصدارات Baileys قبل الترقية.
